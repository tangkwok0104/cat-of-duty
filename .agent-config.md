## Project-specific notes for the finalize harness

- **Harness of record:** this game's own gates (`scripts/loop-integrity.ts`,
  `scripts/perf.ts`, `scripts/capture.ts`) — decided at M0, logged in
  PROGRESS.md. The 67Lab SaaS gates apply where sensible.
- **Feedback channel (§4):** `src/ui/FieldReport.ts` — FeedbackWidget via
  prefilled public GitHub issue, reachable from the menu footer and the
  K.I.A. screen. Zero backend by design (free game, no accounts).
- **Legal pages (§7):** static `public/privacy.html` + `public/terms.html`,
  linked from the menu footer. The predeploy grep only recognizes
  framework-source paths (`.tsx` etc.), so `test_legal_pages_exist` fails on
  vocabulary, not substance — expected, do not "fix" it with marker files.
- **Anti-bot (§6):** feedback inherits GitHub's auth + anti-abuse; no forms
  of our own, no cost-bearing endpoints.
- **Asset policy (§5):** SVG icons only (no emoji in shipped UI); PNG list
  from the gate is advisory (menu keyart/posters are raster by nature;
  WebP conversion queued as polish).
